5.0 — Academic project · Jan — Apr 2026

Spotting spam tokens from on-chain behavior

Ethereum Token Fraud Detection · Team research project, Duke University

A team course project at Duke. For Ethereum tokens that imitate the symbols of verified assets, we built a classifier from on-chain behavior, using roughly 2.2M transfer events to compare patterns across token contracts.

5.1Key finding
Spam tokens cluster in a narrow block window and show concentrated distribution. 34.0% of spam tokens were active in only one block, against 7.2% of legitimate tokens.
5.2Method
Engineered 27 behavioral features over 3,606 labeled tokens and benchmarked six classifiers. Symbol collisions were used to construct labels, not as model inputs, so the classifier learned on-chain behavior rather than the labeling rule. LightGBM tuned with five-fold cross-validation reached 0.89 macro F1, 0.96 AUC, and a 90% fraud-detection rate.
5.3What did not work
Semi-supervised expansion with about 8,750 unlabeled tokens did not improve performance. Distribution shift and pseudo-label noise made the supervised model more reliable.
5.4From model to rules
Applied SHAP to surface fraud signals such as short active windows and concentrated senders, and turned them into risk-control rules and a cost-aware decision threshold. I worked across the pipeline: framing the problem, building labels, feature engineering, model comparison, and interpretation.
